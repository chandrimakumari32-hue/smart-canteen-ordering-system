
 # Campus Canteen — Smart Canteen Ordering System

A web-based Smart Canteen Ordering System designed for a college campus.

##  Live Demo

[View the Live Website] https://chandrimakumari32-hue.github.io/smart-canteen-ordering-system/

##  About the Project

Campus Canteen is an interactive web application that provides a digital canteen ordering experience.

Users can browse food items, search and filter the menu, select multiple items and quantities, view their bill, apply available discounts, select a payment method, and place an order.

This project was created as a student project to explore **AI-assisted development and prompt engineering** for building a functional web application.

##  Features

-  Food menu with prices
-  Search food items
-  Food categories
-  Vegetarian filter
-  Add multiple food items
-  Increase or decrease quantities
-  Automatic bill calculation
-  Discount calculation
-  Cash, UPI and Card payment options
-  Order token generation
-  Order history
-  Food descriptions and ingredients
-  User-friendly interface

##  Technologies Used
